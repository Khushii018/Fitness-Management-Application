# Fitness Management Application 🏋️

A mobile fitness application built with **React Native** to provide a user-friendly interface for fitness management and workout-related activities.

## 📱 About the Project

Fitness Management Application is a frontend mobile development project created using React Native. It focuses on a clean user interface, reusable components, and smooth navigation between screens.

## ✨ Features

- User-friendly mobile interface
- Fitness-related screens and dashboards
- Navigation between application screens
- Reusable UI components
- Local data storage using AsyncStorage, where implemented
- Form handling and validation using React Hook Form and Zod, where implemented

## 🛠️ Technologies Used

- **React Native** — Mobile application development
- **TypeScript** — Type-safe JavaScript development
- **React Navigation** — Screen navigation
- **Redux Toolkit** — State management
- **AsyncStorage** — Local data persistence
- **React Hook Form** — Form management
- **Zod** — Data validation

## 🚀 Getting Started

### Prerequisites

Install the following before running the application:

- Node.js
- npm
- Android Studio and Android SDK for Android development
- JDK compatible with the project's Android Gradle configuration

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Khushii018/Fitness-Management-Application.git
```

**2. Navigate to the project directory**

```bash
cd Fitness-Management-Application
```

**3. Install dependencies**

```bash
npm install
```

**4. Start Metro**

```bash
npm start
```

**5. Run the Android application**

Open another terminal in the project directory:

```bash
npm run android
```

Make sure an Android emulator is running or a compatible Android device is connected.
